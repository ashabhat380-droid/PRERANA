# CampusCare Frontend

React Native + Expo + TypeScript + Expo Router frontend scaffold for the CampusCare beneficiary journey.

## Run the project

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Confirm the prompt ends with `CampusCare-frontend>`.
4. Run:

```bash
npm install
```

5. After installation finishes, run:

```bash
npx expo start
```

6. Press `w` to open the web version, or scan the QR code with Expo Go.

## Main flow

Welcome → Wellbeing Check-in → Objective OR Projective → Results → Dynamic Monitoring → Support & Next Steps

Emotional Expression is an optional, persistent enrichment module accessible from the main journey; it is not a mandatory gate.

## Important

This is a frontend scaffold. It contains demo/mock assessment and monitoring data and is ready to be connected to the CampusCare Spring Boot backend later.
